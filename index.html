Перший вхід виконаємо через Microsoft Teams. Після активації цей самий обліковий запис використовуватиметься для входу в сервіси Microsoft 365.

Перевіримо, чи встановлено Microsoft Teams

1

Microsoft Teams · Встановлення

Встановіть Teams через Microsoft Store

Це основний спосіб встановлення, якщо Teams відсутній на комп'ютері.

1
Натисніть «Пуск» і введіть Microsoft Store
Відкрийте програму Microsoft Store.
2
У пошуку Microsoft Store введіть Microsoft Teams
Виберіть офіційний застосунок Microsoft Teams.
3
Натисніть «Встановити»
Дочекайтеся завершення встановлення та відкрийте Teams.
Альтернативний спосіб

Завантажте Teams з офіційного сайту Microsoft

Якщо Microsoft Store не працює, програму можна встановити через браузер.

1
Відкрийте браузер
Наприклад Microsoft Edge або інший браузер, яким ви користуєтесь.
2
У пошуку введіть «Microsoft Teams»
Відкрийте офіційну сторінку Microsoft.
3
Завантажте Teams для Windows
Після завантаження відкрийте файл встановлення та пройдіть кроки на екрані.
Якщо Windows просить права адміністратора і ви не можете продовжити встановлення — зверніться до адміністратора. Самостійно обходити це обмеження не потрібно.

Після успішного підтвердження система перейде до зміни пароля.

На наступному кроці окремо покажемо, як відкрити OneDrive і працювати з файлами.

1

OneDrive · Папки та файли

Створюйте папки та завантажуйте робочі файли

Усе, що ви зберігаєте в OneDrive, доступне через ваш корпоративний обліковий запис.

1
Створити папку
Оберіть створення нового елемента, виберіть «Папка», дайте їй зрозумілу назву та відкрийте її.
2
Завантажити файл або папку
Оберіть завантаження та виберіть потрібний файл або папку на комп'ютері.
3
Альтернативний спосіб — перетягування
Можна просто перетягнути файл або цілу папку з Провідника Windows прямо у вікно OneDrive. Після цього почнеться завантаження.
4
Перевірити, що дані з'явилися у списку
Після завантаження файл або папка буде доступна у вашому OneDrive.
Важливо: файл зберігається у вашому корпоративному OneDrive. Після входу в той самий mil-акаунт файл можна відкрити з будь-якого пристрою.
OneDrive · Доступ до файлів

Підключення OneDrive до комп’ютера — необов’язкове

Ви вже можете користуватися OneDrive через Teams і відкривати свої файли після входу в mil-акаунт на будь-якому пристрої. Додатково OneDrive можна підключити безпосередньо до Windows.

↻
Що дає підключення OneDrive до ПК

Ваші робочі файли з’являться у Провіднику Windows як звичайна папка. Файли можна буде перетягувати, відкривати та зберігати так само, як інші файли на комп’ютері, а зміни синхронізуватимуться з OneDrive.

1
Швидкий доступ через Провідник Windows
Не потрібно щоразу відкривати Teams, щоб знайти робочий файл.
2
Автоматична синхронізація змін
Файли у папці OneDrive синхронізуються з вашим корпоративним сховищем.
3
Можливість зберігати потрібні файли локально
За потреби окремі файли або папки можна зробити доступними на комп’ютері навіть без підключення до мережі.
Необов’язково · OneDrive на комп’ютері

Підключимо OneDrive до Windows

Після налаштування у Провіднику Windows з’явиться папка OneDrive, яка синхронізуватиметься з вашим корпоративним сховищем.

1
Натисніть «Пуск»
Почніть вводити слово OneDrive.
2
Відкрийте програму Microsoft OneDrive
З'явиться вікно входу до OneDrive.
OneDrive не знайдено

Якщо програми OneDrive немає

На більшості робочих комп'ютерів Windows OneDrive уже встановлено. Якщо пошук його не знаходить, не потрібно самостійно змінювати системні налаштування.

Зверніться до адміністратора або відповідальної особи, щоб перевірити встановлення OneDrive на вашому комп'ютері.
OneDrive · Підключення до ПК

OneDrive може автоматично запропонувати ваш mil-акаунт

Якщо під час першого входу ви підтвердили використання корпоративного облікового запису на цьому пристрої, Windows може вже мати дані вашого mil-акаунта.

Якщо OneDrive одразу показує ваш mil-акаунт — просто підтвердьте його та продовжуйте. Повторно вводити пошту і пароль не потрібно.
1
Перевірте, який обліковий запис пропонує OneDrive
Якщо бачите свою корпоративну адресу — підтвердьте її.
2
Якщо обліковий запис не з’явився автоматично
Введіть корпоративну пошту та новий пароль, який ви створили під час першого входу.
3
Пройдіть стандартне налаштування OneDrive
Коли OneDrive запропонує розташування папки, для звичайного користувача достатньо залишити запропонований варіант і продовжити.
OneDrive · Провідник Windows

Тепер OneDrive доступний у Провіднику Windows

У Провіднику Windows з’явиться папка OneDrive вашої організації. Її вміст синхронізується з корпоративним OneDrive.

# dsst.mil.ua Microsoft 365 onboarding guide

Статична HTML-інструкція, підготовлена для GitHub Pages.

## Публікація через GitHub Pages

1. Створіть новий GitHub-репозиторій.
2. Завантажте в корінь репозиторію:
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. Відкрийте:
   `Settings → Pages`
4. У розділі **Build and deployment** виберіть:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Натисніть **Save**.
6. Через кілька хвилин GitHub покаже адресу опублікованої сторінки.

## Структура

- `index.html` — готова інструкція
- `.nojekyll` — вимикає Jekyll-обробку
- `README.md` — ця інструкція

Сторінка не потребує серверної частини або збірки.
